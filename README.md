# 💰 Expense Tracker

A full-stack **personal finance management system** built using Django and MySQL (via XAMPP). This web app allows users to manage their incomes and expenses efficiently.

## 🚀 Features

- Add, edit, and delete income and expense records
- Categorize transactions by type
- View total income, expense, and current balance
- Responsive dashboard and history view
- User registration and login system
- Secure backend powered by Django ORM
- Local MySQL database integration using XAMPP

## 🛠️ Tech Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, Bootstrap, Django Templates
- **Database:** MySQL (XAMPP)
- **Other Tools:** XAMPP, Git, GitHub

### Prerequisites

- Python 3.8+
- pip
- XAMPP (for MySQL server)
